# Competition

An entity representing a Competition in TypeRacer

## Fields

| Field       | Type     | Description                                |
|-------------|----------|--------------------------------------------|
| `uid`       | string   | The unique id of the Competition           |
| `name`      | string   | The name of the Competition                |
| `starts_at` | DateTime | The start date and time of the Competition |
| `ends_at`   | DateTime | The end date and time of the Competition   |
