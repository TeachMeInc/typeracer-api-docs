# CompetitionResultV2

An entity representing the results of a Racer for a given Competition

## Fields

| Field      | Type   | Description                                         |
|------------|--------|-----------------------------------------------------|
| `username` | string | The username of the Racer                           |
| `points`   | number | The points the Racer accumulated in the competition |
| `avg_wpm`  | number | The average wpm of the Racer in the competition     |
| `best_wpm` | number | The best wpm of the Racer in the competition        |
| `rank`     | number | The rank of the Racer in the competition            |
